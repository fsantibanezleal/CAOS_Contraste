## producer-checks

The cross-field rules JSON Schema cannot hold. The reference implementation is `tests/contracts_u14/semantics.py` (`check_c02`, `check_c20`, `check_c21`, each returning a list of messages, empty when the document conforms): the U14-P briefs carry it, the bakes call it on every document they write (a non-empty list is a refusal to publish) and the producer tests run it over every committed document. The four-fifths flag is decided on the counts in exact arithmetic, never on a float ratio.

### c02-outputs
- Producer U14-P1; `semantics.check_c02`.
- Counts: events <= rows, event_rate = events / rows, the three split slices add to the rows, holdout events <= holdout rows and <= events; the pooled files (years 1 to 5 once each) add to the counts.
- Per rung: the AUC lies inside its interval and lo <= hi; gini = 2 auc - 1; the overfit gap = train AUC - holdout AUC and the flag = (gap > tolerance), with the tolerance the named parameter `overfit_tolerance`; ROC and CAP arrays have equal lengths, never decrease and run from 0 to 1; reliability bins have lo <= dr <= hi and increasing PD.
- Challenger: each difference lies inside its interval.
- Term structure: years 1 to 5 in order, `cumulative_nondecreasing` agrees with the points, cumulative = 1 - product of (1 - hazard) within 1e-3.
- Named parameters carry the approved values (decision V6).
- Enumerated in the schema (not a producer check): `horizon_id` with `years`.

### c02-models
- No cross-field rule beyond the schema; the named parameter values are the approved ones.

### c20-outputs
- Producer U14-P2; `semantics.check_c20` (shock kind).
- `n_reaching_structured_view` <= `n_records`; `psi_max` and `csi_max` are the maxima of the per-variable rows; the cut-off reject share and every named parameter equal the approved values.
- The batches of a row are the SGCD batches (S, A or T) of its shock; the seen and held-out split is the protocol's, not a free choice.

### c20-outputs-shift
- Producer U14-P2; `semantics.check_c20` (shift kind).
- `target_coverage` = 1 - alpha; the windows average (weighted by n) to the overall coverage; the CBPE estimate row is never labelled measured.

### c20-outputs-seeds
- Producer U14-P2; `semantics.check_c20` (seeds kind).
- AUC min <= mean <= max; `n_seeds` and `n_refits` are the named parameters; per explainer row, `rank_correlation` is null exactly when `reason_if_null` is set, the ALE edges increase with one effect per bin, and there are at most `n_features` top features.

### c20-outputs-perturbation
- Producer U14-P2; `semantics.check_c20` (perturbation kind).
- `preset_eps` is a grid point; the `finding` at the preset scale equals (-auc_delta > `perturbation_tolerance`).

### c20-outputs-leakage
- Producer U14-P2; `semantics.check_c20` (leakage kind).
- `suspect` = (max_auc > the single-feature limit); `caught` agrees with the four screens (a future-dated value, a suspect single feature, any entity overlap, a resemblance AUC above its limit).

### c21-outputs
- Producer U14-P3; `semantics.check_c21`.
- Per group: n_approved + n_denied = n and selection_rate = n_approved / n (exact counts from the source rows).
- Four-fifths: `highest_rate_group` is the first group of the highest rate (compared on `fractions.Fraction`); one row per group; `ratio_to_highest` = rate over the highest rate; `flag` = 5 * x_g * n_h < 4 * x_h * n_g in exact arithmetic (60/100 against 75/100 is not flagged).
- Contrasts: a group against the attribute's reference group, never against itself; sizes and rates equal the group counts; parity gap = rate difference; parity ratio and AIR = rate over the reference rate (null when it is 0); the z-test is the pooled two-proportion test; the Fisher odds ratio is the sample odds ratio; each interval contains its coefficient and the odds ratio = exp(coefficient).
- Confirmation: `fit_year` and `confirm_year` equal the pair's years, `same_sign` agrees with the coefficients and `size_ratio` = confirm / fit (null when the fit coefficient is 0).
- Situation testing: n_significant <= n_cases <= n_complainants.
- HMDA identity (decision V3): the reader writes id = `<activity_year>-<row>` and observation_date = `<activity_year>-12-31`, both labelled conventions; a dataset that declares `outcome: none` carries `decision`.
- Enumerated in the schema (not a producer check): `pair_id` with its two years; the group names of each attribute.

### c21-models
- No cross-field rule beyond the schema; the conventions block repeats the outputs'.
