# Requirements: the methods compared across the questions of the benchmark (task T2, the document and its contract)

Status: live

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated. The step is
`data-pipeline/pipeline/benchmark/methods.py` (`python -m pipeline.benchmark.methods` from `data-pipeline/`); the document is
`data/derived/benchmark/methods-compared.json` (contract `benchmark-methods` 1.0.0, the producer side). The design is
[`design.md`](design.md); the adversarial checks are [`validation.md`](validation.md); the tasks (T3 renders the document on the Benchmark
page, T4 points the Introduction, Experiments and the technical report at it) are in [`tasks.md`](tasks.md).
