# Adversarial validation: C11 (market VaR and ES back-testing across 2008, 2020, 2022 and 2023)

One row per requirement of [`requirements.md`](requirements.md): what is planted or refuted, and the test that does it. Each gate is a test of `tests/c11/` whose name starts with `test_adversarial`: it plants the defect in the check's input and asserts that the clean input passes and the planted one is found.
