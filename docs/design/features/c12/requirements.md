# Requirements: U9-P1, case C12 (swap exposure, CVA and SA-CCR on a synthetic USD swap book)

Status: live

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated. The bake is
`data-pipeline/pipeline/cases/c12/`; the documents are `data/derived/C12/` (contracts `c12-outputs`, `c12-models`, `case-manifest` and
`variant-envelope`, the producer side); the methods are `riskvalidation.ccr` and `riskvalidation.regulatory` (engine contracts
`engine-ccr-api` 2.0.0 and `engine-regulatory-api` 2.0.0, the consumer side). The design is [`design.md`](design.md); the adversarial
checks are [`validation.md`](validation.md).

|---|---|---|
