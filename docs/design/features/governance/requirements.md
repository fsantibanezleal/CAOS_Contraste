# Requirements: U15-P, the governance bake (model inventory, tiers, findings register, appetite and validation reports)

Status: live

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated. The bake is `data-pipeline/pipeline/governance/`; the documents are `data/derived/governance/` (contracts `governance-inventory`, `governance-findings`, `governance-report` and `governance-appetite` 1.0.0, the producer side); the methods are `riskvalidation.governance` (engine contract `engine-governance-api` 1.0.0, the consumer side). The design is [`design.md`](design.md); the adversarial checks are [`validation.md`](validation.md). Nothing here approves a model or claims compliance (SDD non-goal 1).
