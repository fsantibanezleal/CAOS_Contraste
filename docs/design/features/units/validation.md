# Adversarial validation: the units gates

One row per requirement of [`requirements.md`](requirements.md): what is planted, and the test under `tests/product_plants/`
(it needs the pipeline) or `tests/adversarial/` (standard library and jsonschema only) that plants it in a throwaway copy of the
committed files, runs the existing gate on the copy and asserts that the clean copy passes and the planted copy fails.
