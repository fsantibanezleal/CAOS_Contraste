The code, the data and the computational outputs are in the repository \pth{github.com/fsantibanezleal/CAOS_Contraste}. The paper describes release v1.00.000 of \pth{CAOS_Contraste} (tag \pth{v1.00.000}). The method is the module \pth{riskvalidation.transitions.withdrawals} of the engine \pth{riskvalidation} 1.1.0, published on the Python Package Index, and its documentation in the engine repository (\pth{docs/transitions/06_withdrawal-bounds.md}) states the model and the assumptions. The product's study, the real-data function and the criteria of Section~\ref{sec:experimental-design} are in \pth{data-pipeline/pipeline/cases/c04_bounds.py}, and its documents, one per agency and one for the known-truth withdrawals family, are \pth{data/derived/C04/sp.json}, \pth{fitch.json} and \pth{withdrawals.json}. The cohorts are the aggregates of the central repository of ESMA (\pth{registers.esma.europa.eu/cerep-publication}), reproduced as its terms allow with the source acknowledged.

Every number of the paper is read from those documents or from the outputs of the scripts of this paper by the table script, and no number of the prose is typed. From the repository root, with the engine installed in a Python environment,
\begin{itemize}
\item \pth{experiments/extended_study.py} runs the coverage grid, the capture ladder, the stability study, the scale ladder and the duration comparison, each with the option \pth{--only} to run one, and writes the JSON files of \pth{experiments/results/};
\item \pth{experiments/theory_checks.py} runs the numerical checks of the propositions;
\item \pth{experiments/crosscheck_pipeline.py} reproduces the product's committed function on the same seed and compares the coverage of every treatment;
\item \pth{tables/make_tables.py} writes the tables and the file of numbers, and \pth{figures/make_figures.py} the figures, both from the committed documents and the results;
\item \pth{pdflatex}, \pth{bibtex} and two more \pth{pdflatex} runs from the manuscript folder build the paper.
\end{itemize}
The elapsed time of each study is measured by \pth{experiments/extended_study.py}, which writes it to \pth{experiments/results/run-times.json} with the machine and the library versions; Table~\ref{tab:runtimes} gives it, the longest study taking \nv{rt.max} minutes; the machine was shared with other jobs while they ran, so the times are upper bounds of a quiet machine's. The machine has \nv{rt.cpus} logical processors (\nv{rt.cpu}), Python \nv{rt.python}, NumPy \nv{rt.numpy}, SciPy \nv{rt.scipy} and the engine \nv{rt.engine}. A rerun of the coverage grid and of the cohort-size ladder with the default repetitions and seeds reproduces their output files byte for byte. The rerun of the stability study with the second source drawn over each grade's own observed ratio range reproduced its four earlier second sources unchanged. The seeds are pure functions of the case seed \nv{case.seed} and the key of each cell (Table~\ref{tab:design}), so a cell can be rerun alone.
