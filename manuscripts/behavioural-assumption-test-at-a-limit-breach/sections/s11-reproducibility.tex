\section{Reproducibility}
\label{sec:reproducibility}

The code, the stored results and the data pipeline are in the repository \url{https://github.com/fsantibanezleal/CAOS_Contraste}, at release \docversion{} of CAOS\_Contraste (tag \texttt{v1.00.000}), and the engine is the package \texttt{riskvalidation} 1.1.0 on the Python package index \citep{riskvalidation2026}. The experiments are scripts under \path{manuscripts/behavioural-assumption-test-at-a-limit-breach/experiments/}, run from the repository root with the Python environment of the product (\texttt{riskvalidation} 1.1.0 with the market, machine-learning and stress extras, and the requirements of the pipeline): \texttt{run\_reproduction.py} writes the stored-history and enumeration results, \texttt{run\_stated.py} the stated population, \texttt{run\_fitted.py} the re-estimated population and the real-series draws, and \texttt{run\_theory.py} the checks of the propositions. Each writes a JSON document next to it, \texttt{results\_reproduction.json}, \texttt{results\_stated.json}, \texttt{results\_fitted.json} and \texttt{results\_theory.json}, which are kept in the repository; the scripts draw every random number from the seeds in those documents and a rerun reproduces them. The unit tests of the shared core, \texttt{test\_core.py}, check the engine against the closed-form count, the statistics, the generators and the decision rules. The tables and the numbers of the text are written by \texttt{make\_tables.py} into \texttt{tables/}, including \texttt{tables/numbers.tex}, which defines one macro for each number quoted in the prose and records its source; the figures are written by \texttt{make\_figures.py} into \texttt{figures/} as vector files. % voice-ok: citation of the product release the results were produced with

The raw inputs of case C14, the call-report file of the FDIC and the Treasury yield files, are read from the data root of the device (the environment variable \texttt{CONTRASTE\_DATA}) and are identified by the digests of the stored documents; the stored documents under \texttt{data/derived/C14/} are the other input. Every script was rerun: the unchanged parts of the experiments gave their earlier results to the last digit, and a rerun after the last change of the scripts is byte for byte equal to the stored document. On an idle workstation with 32 cores \texttt{run\_reproduction.py} takes about 10 seconds, \texttt{run\_stated.py} about 40 seconds, \texttt{run\_theory.py} about 1 minute and \texttt{run\_fitted.py} about 3 minutes with an empty cache, the longest because it fits the replicating portfolio on every window of every bank; on a shared machine each took under 6 minutes, and \texttt{make\_figures.py} takes about 2.5 minutes. The cache of the fitted weights, which is not stored, is written to the temporary root of the device and rebuilt when absent. The document is built with \texttt{pdflatex} and \texttt{bibtex} from the manuscript folder.
