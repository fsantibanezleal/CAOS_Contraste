\section{Reproducibility}
\label{sec:reproducibility}

The source, the committed documents and the scripts are in the repository named in the header of the paper.
The engine is \texttt{riskvalidation} 1.1.0 from the Python Package Index, and the C06 and C07 documents were baked on it.
Each experiment is one script run from the repository root with the product's interpreter, \texttt{python manuscripts/provisions-reconciliation-identities/experiments/e1\_gate\_power.py} and likewise for the scripts \texttt{e2} to \texttt{e6}; the fifth is run with a list of seeds and a list of sizes, once for the ten seeds at full size and once for seed 42 at six sizes.
Each writes compact JSON next to itself with sorted keys, and a rerun with the same seeds gives the same bytes; the seed of every draw is derived from a base seed and the indices of the experiment.
The measured run times are \eoneSeconds{} seconds for the first, \efourSeconds{} seconds for the fourth (on a workstation running other jobs) and \efiveSecLow{} to \efiveSecHigh{} seconds for one build of the six scenarios at full size.
The numbers quoted in the text are macros written by \texttt{make\_numbers.py}, the tables by \texttt{make\_tables.py} and the vector figures by \texttt{make\_figures.py}, all from the experiment outputs; the references are written by \texttt{fetch\_references.py} from the publishers' records.
The datasets are the six committed C06 documents and the six committed C07 documents with the models document; the raw SBA files are public and are read only by the C06 bake.
