The code, the data and the commands are in the repository of the product, \url{https://github.com/fsantibanezleal/CAOS_Contraste}, at release v1.00.000 of CAOS\_Contraste (tag v1.00.000). % voice-ok: citation of the product release the results were produced with
The code, the derived data and the outputs of this study are in the folder \texttt{manuscripts/}\allowbreak\texttt{uf-as-its-own-currency-in-irrbb}. The engine is \texttt{riskvalidation} 1.1.0 and the committed documents of the published case, with the seed 42 and the six variants, are in \path{data/derived/C15}.

The raw inputs are the Banco Central de Chile yields and the UF value, and a reader obtains them from the central bank's statistical database. The series are those of Table~\ref{tab:data}: the peso yields \texttt{F022.BCLP.TIS.AN02}, \texttt{AN05} and \texttt{AN10}, the UF yields \texttt{F022.BUF.TIS.AN02}, \texttt{AN05}, \texttt{AN10} and \texttt{AN30}, the policy rate \texttt{F022.TPM.TIN.D001.NO.Z.D} and the UF value \texttt{F073.UFF.PRE.Z.D}, for September 2026, with the valuation date \valDate{}. They are served by the web service of the database, which requires a registration with a user and a password. The file \path{data/derived/C15/raw-sources.txt} of the repository records, for each raw file, the address that returned it, its size, its SHA-256 digest and the date it was retrieved; no experiment queries the central bank. The command \texttt{python -m pipeline.io.bcch fetch --data-root <root> --first 2026-09-01 --last 2026-09-30}, run from the folder \texttt{data-pipeline} with the user and the password of the database in the environment variables \texttt{BCCH\_USER} and \texttt{BCCH\_PASSWORD}, writes the files, the series listing \texttt{search-daily.json} and a record \texttt{provenance.json} into \texttt{<root>/raw/bcch-f022}. The code refuses a file that differs from that record. The digests of the files used here are in \path{data/derived/C15/raw-sources.txt}, and a reader compares the two records to confirm the same bytes. The folder \texttt{<root>} is the one named by the environment variable \texttt{CONTRASTE\_DATA}, or passed to the experiments with the argument \texttt{--data}.

From the root of the repository, in the order given, the scripts of the folder \texttt{experiments}, \texttt{exp\_reproduce.py}, \texttt{exp\_main.py}, \texttt{exp\_sweep.py}, \texttt{exp\_floors.py} and \texttt{exp\_ratio\_\allowbreak of\_means.py}, run with \texttt{python}, write the five JSON outputs, \texttt{figures/\allowbreak make\_figures.py} writes the eight figures and \texttt{tables/\allowbreak make\_tables.py} writes the ten tables and the macros of every number quoted in the text. The experiments are deterministic given the seeds stated in Section~\ref{sec:design-protocol} and, for the bootstrap, the seed stated in the script, and the module \texttt{uf\_core} builds nothing that the engine or the generator of the case does not. The measured run times are \repSeconds{} seconds for the reproduction, \mainSeconds{} for the main comparison and its decomposition, \sweepSeconds{} for the sweep, \floorsSeconds{} for the floor experiment and \ratioSeconds{} for the ratio of means, \totalSeconds{} seconds in all, on one workstation with an Intel Core i9-14900HX processor and 48 GB of memory, written by the scripts into the JSON outputs.
